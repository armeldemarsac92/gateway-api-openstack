# Proportional UDP packet discard

Set `--octavia-udp-packet-drop` on the Gateway controller in a region running the Amphora API, worker and data plane that implement `udp_packet_drop_v1`. The setting defaults to off. It applies on both Gateway API v1.7.0 channels to the dedicated UDP Gateways managed by this controller instance. Eligible Gateways use an IPv4 VIP and a GatewayClass with `memberMode: Endpoint`. An eligible route wins on exactly one listener. Separate routes on different listeners can use the feature independently. Routes sharing one pool across several listeners, IPv6 Gateways and NodePort members use ordinary UDP forwarding.

The extension uses one dedicated round-robin pool per selected listener and requires an empty default before the first managed member batch. The controller omits the class's UDP-CONNECT monitor on these pools and uses EndpointSlice readiness. Enabling the option can briefly interrupt an existing eligible listener while the controller replaces its stock pool and UDP-CONNECT monitor. The route's `Programmed` condition stays pending until Octavia reports the new pool active. The listener and Gateway keep their identities.

For backend weights 3 and 1, removing the ReferenceGrant for the second Service reserves one quarter of the traffic for discard. The valid Service continues to get three quarters and the unauthorized Service receives no new traffic once Octavia applies the batch. Missing Services and Services with no eligible endpoints also contribute their positive weights. A zero-weight invalid reference contributes only diagnostics. An all-unavailable pool has no real members and discards all traffic.

Check the route's `Accepted`, `ResolvedRefs` and `<controller-domain>/Programmed` conditions independently. A revoked reference yields `ResolvedRefs=False` while `Programmed=True` can confirm the valid members and packet discard share. Endpoint loss can leave `ResolvedRefs=True`. The route reports programmed only after the active pool reports the exact fraction and member set. To qualify a deployment, send fresh UDP flows before revoking a grant, after provisioning the new fraction and after restoring the grant. Count traffic at both Services and verify a separate listener during each phase.

## Disable the feature

Remove the flag while the patched API and worker are available. The controller deletes the owned guarded pool and its default edge. A route with all active destinations available gets a stock pool with its class monitor. A route with an unavailable positive-weight backend stays withdrawn until its destinations are usable. A lost regional capability follows the same fallback. Verify the affected listener defaults and confirm that the guarded pools are gone before downgrading Octavia.
