# API contracts beyond named conformance features

Local HTTP traffic and status are recorded for the Experimental XBackend EndpointSelector and Service retry budget. On a local Istio ambient installation, XMesh withdrew and restored its reported features as istiod stopped and recovered. An Experimental XTelemetryPolicy exported request spans to a collector Pod, withdrew export after its ReferenceGrant was removed and restored it when the grant returned. ## Contracts exercised by this fork

| Contract | Input, observed result and remaining boundary |
|---|---|
| Complete release inventory and `SupportedVersion` | Separate local Kubernetes API servers accept each genuine selected v1.7.0 bundle. A controller configured for the opposite channel rejects it. A same-version fixture with mixed channel annotations blocks provisioning. [Controller checks](../../../../internal/controller/envtest_test.go) |
| Unsupported listener filters | The Experimental API accepts the filter request. The controller rejects the listener before binding and cleans up an already-bound listener whose filters cannot be enforced. [Listener reconciliation](../../../../internal/controller/gateway/reconciler_test.go) |
| Listener and route hostname intersection | The opt-in TLS listener accepts a route's intersecting exact SNI names, including multiple names for one Service. [TLS passthrough and hostname selection](../../../operator-octavia-tls-sni-passthrough.md#route-two-names-on-one-port) A plain HTTP listener can route each distinct hostname pattern that survives the intersection. Omitted names and leading wildcards use the same intersection and precedence rules. [Multiple hostname declarations](../provider/http-host-intersection.md) The backend receives the original Host including a numeric port. Disjoint names are rejected, the wildcard excludes the apex, and the effective regular expression must fit Octavia’s 255-character field. Original route names break ties on a shared listener. Deployed Amphora and strict handling of malformed authorities remain open. [Hostname evidence](../../../providers/hibiscus-exact-hostname.md) |
| Listener allowed route kinds | The controller reports only selectable kinds for each listener and sets `ResolvedRefs=False/InvalidRouteKinds` for an invalid kind even when another listener setting is also unsupported. The v1.7.0 case uses both an invalid-only and a mixed kind list. [Upstream status checks](../../../../internal/controller/envtest_upstream_status_test.go) |
| Independent listener status and route attachment | A Gateway with one HTTP listener and an unsupported protocol on another port accepts the valid listener. Selecting that HTTP listener by section and port preserves its port and hostname. Selecting the unsupported listener gives `NotAllowedByListeners`. A section and port with no matching listener give `NoMatchingParent`. [Controller cases](../../../../internal/controller/httproute/reconciler_test.go) |
| Shared Gateway authorization | Two same-named routes bind through a Namespace selector. Revocation clears one binding and changes `attachedRoutes` from two to one. The upstream `HTTPRouteInvalidCrossNamespaceParentRef` case checks `Accepted=False/NotAllowedByListeners`, `ResolvedRefs=True` for an existing Service and zero routes on a Same listener. [Kubernetes watch test](../../../../internal/controller/envtest_references_test.go) · [Upstream status cases](../../../../internal/controller/envtest_upstream_status_test.go) · [Selective removal and traffic](../cloud-contract.md#two-routes-on-a-shared-listener) |
| Service reference permission | On stock Octavia the controller removed the revoked route fragment. With the fixed-response and weighted actions enabled, the share assigned to a denied Service received HTTP 500 and the Service received zero requests. Restoration returned that share to the Service. [Stock NodePort result](../service-grants.md) · [Both opt-in transitions](../provider/weighted-referencegrant-e6fbd1a/validation-referencegrant.md) |
| Explicit HTTPRoute retry backoff | A forwarding rule can set the interval between eligible attempts. The same route exercised a positive interval, total and per-attempt deadlines, explicit zero and removal on both channels. [Timing and provider readback](../provider/http-retry-backoff.md) |
| Owned graph deletion after a lost response | A fresh Gophercloud adapter discovers the remaining graph and deletes only owned resources. The simulated inventory retains both control load balancers. [Scoped cleanup evidence](../cloud-contract.md) |

| [XBackend](https://github.com/kubernetes-sigs/gateway-api/blob/e26d183dbbc1bb782b78addbd26faba03955c152/apisx/v1alpha1/xbackend_types.go) | Experimental HTTPRoute in Endpoint mode selects ready IPv4 Pods using every label in the same-namespace XBackend and uses its literal port. A local kind Gateway followed an ExternalHostname from A to B, returned 503 during NXDOMAIN and served A again after recovery. The HTTPRoute and XBackend kept their original generations. The backend TLS option supports ServerOnly with HTTP or HTTP/1.1. On kind, an EndpointSelector with an authorized CA served HTTP/1.1 over TLS, returned HTTP 503 after its CA was withdrawn and recovered after restoration. A separate DNS-origin certificate mismatch returned HTTP 503. [Traffic, identity and conditions](../provider/xbackend-server-tls-evidence/receipt.json) With the regional `http_cookie_name_v1` capability and a controller opt-in, an EndpointSelector can use a named or generated session cookie with path `/`. On kind, two route paths selecting the same XBackend held one session on the same Pod. Marking it unready moved the session to the other Pod and renewed its cookie. A separate ServerOnly backend issued its own cookie and negotiated HTTP/1.1. [Session cookies and endpoint failover](../provider/xbackend-session-cookie-evidence/receipt.json) With a separate operator enrollment, the controller configures an XBackend client identity for ClientAndServer. On a local Experimental Gateway, the selected Pod required the enrolled client certificate. Restoring the grant returned HTTP 200, and the Pod observed the new certificate after rotation. [ExternalHostname mutual TLS](../provider/xbackend-external-client-tls-evidence/receipt.json) An optional absolute timeout limits affinity across HTTPRoutes that share the same XBackend. [Timed cookie traffic](../provider/xbackend-cookie-deadline-evidence/receipt.json) With permanent cookies enabled, the local Experimental trial verified client retention and the gateway deadline on two HTTPRoutes. [Persistent cookie observations](../provider/xbackend-permanent-cookie-evidence/receipt.json) A custom cookie Path limited affinity to the configured request path and descendants across three HTTPRoutes. [Cookie jar results](../provider/xbackend-cookie-path.md) A deployed Hibiscus trial, header persistence and additional route kinds remain open.
