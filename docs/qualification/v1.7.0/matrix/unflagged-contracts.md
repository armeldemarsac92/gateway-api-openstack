# API contracts beyond named conformance features

Use [api-field-catalog.csv](api-field-catalog.csv) to filter 473 Go struct fields by package, type, JSON tag, literal support annotation or comment excerpt; the final column links to the complete upstream field comment. It covers `*_types.go` in `apis/v1`, `v1alpha2`, `v1alpha3`, `v1beta1` and `apisx/v1alpha1`. Empty support means no literal annotation on that field, not that the field is unsupported or Core. The [type and value index](type-and-value-catalog.csv) links the complete source for exported declarations, including aliases, enums and type-level comments. Follow embedded types through those links and inspect admission requirements in the [schema constraints](schema-constraints.md). A field can impose several distinct wire or status requirements. The table below is a human-oriented index of key families and decision/test boundaries, not an exhaustive substitute for those links.

## Contracts exercised by this fork

| Contract | Input, observed result and remaining boundary |
|---|---|
| Complete release inventory and `SupportedVersion` | Separate local Kubernetes API servers accept each genuine selected v1.7.0 bundle. A controller configured for the opposite channel rejects it. A same-version fixture with mixed channel annotations blocks provisioning. [Controller checks](../../../../internal/controller/envtest_test.go) |
| Exact HTTP hostname within the supported single-route topology | The provider writes a bounded anchored host predicate and preserves the original Host header. Standalone HAProxy with the stock Octavia template forwarded an uppercase hostname with an explicit port and rejected an unrelated domain. Listener/route hostname intersection and production Amphora are open. [Hostname evidence](../../../providers/hibiscus-exact-hostname.md) |
| Service reference permission | A grant in the backend namespace authorizes the remote NodePort. During grant deletion, the controller reports `RefNotPermitted` and removes only the route fragment. Cross-namespace Gateway attachment and the specified invalid-backend HTTP 500 remain open. [ReferenceGrant evidence](../service-grants.md) |
| Owned graph deletion after a lost response | A fresh Gophercloud adapter discovers the remaining graph and deletes only owned resources. The simulated inventory retains both control load balancers. [Scoped cleanup evidence](../cloud-contract.md) |

## Four Experimental-only resource families

| Resource and type contract | Required design and proposed smallest behavioral check |
|---|---|
| [XBackend](https://github.com/kubernetes-sigs/gateway-api/blob/e26d183dbbc1bb782b78addbd26faba03955c152/apisx/v1alpha1/xbackend_types.go) | Select ExternalHostname or EndpointSelector, port, optional persistence, protocol and TLS. Extended resource; protocol support differs by value and TLS `None` is Core within it. Decide DNS refresh, endpoint selection, trust and persistence representation. Test one endpoint selector, then missing endpoints and TLS trust failure. |
| [XBackendTrafficPolicy](https://github.com/kubernetes-sigs/gateway-api/blob/e26d183dbbc1bb782b78addbd26faba03955c152/apisx/v1alpha1/xbackendtrafficpolicy_types.go) | Apply targetRefs to backend and translate retry budget; exhausted budget requires 503. SessionPersistence is deprecated in favor of Backend. Stock Octavia has no route retry policy. Test exhausted retry budget and target isolation; provider/implementation approach unresolved. |
| [XMesh](https://github.com/kubernetes-sigs/gateway-api/blob/e26d183dbbc1bb782b78addbd26faba03955c152/apisx/v1alpha1/xmesh_types.go) | Cluster-scoped controller identity plus implementation-specific parameters and status; invalid parameters require Accepted=False/InvalidParameters. Decide mesh controller and dataplane ownership; test one accepted controller and invalid parameters. Mesh profile membership is separate from the presence of this CRD. |
| [XTelemetryPolicy](https://github.com/kubernetes-sigs/gateway-api/blob/e26d183dbbc1bb782b78addbd26faba03955c152/apisx/v1alpha1/xtelemetrypolicy_types.go) | Target Gateway and enable/disable tracing, OTLP provider and sampling. Test Enabled without provider is rejected and a configured trace reaches the collector. Decide dataplane/exporter, security and implementation defaults. `TelemetryPolicyTracing` appears in type comments but is absent from the compiled 64-feature registry; do not infer an upstream registered conformance case. |

Standard versus Experimental shared-kind differences include listener and route external-auth fields, route session persistence, address routability, and `ExternalAuth` filter enum values. The [constraint diff](schema-constraints.md) also exposes CEL and minimum-item changes in shared fields; it deliberately compares selected schema keywords, and is not a full semantic equivalence proof. The four resources themselves occur only in the Experimental CRD bundle.
