# Route gRPC calls by metadata

An HTTP listener can select a gRPC backend from exact metadata values when the operator enables h2c pools, fixed HTTP responses and exact header matching. All predicates in one match must agree. Different matches on the rule are alternatives. More specific header combinations take priority. Matching uses full field values and case-insensitive metadata names. [Backend h2c setup](grpc-h2c-controller.md) · [Full-field matching](http-header-exact.md)

On controller `5c8029dd1e40`, the original `GRPCRouteHeaderMatching` case applied a new GRPCRoute to an isolated Kubernetes API server. It passed ten of eleven calls on both v1.7.0 bundles. In each case the request carrying only `color=blue` exceeded the upstream deadline while the route reported `Accepted=True`, `ResolvedRefs=True` and `gateway-api-openstack.github.io/Programmed=False/Pending`.

After the same route reported `Programmed=True` and a six-second TCP health-monitor window elapsed, the original test passed all eleven calls on both bundles. The two expected backends returned their pod identities. Three unmatched calls returned gRPC code 12 (`UNIMPLEMENTED`). Octavia exposed seven ordered policies, two h2c pools and four members. The cold and post-programming results share the upstream test binary, manifest and assertion deadlines. [Standard receipt](grpc-metadata-evidence/standard.json) · [Experimental receipt](grpc-metadata-evidence/experimental.json)

A second cold run used the controller’s default ten-minute resync interval. The earlier fixture had requested a resync every two seconds. Experimental passed 11/11 in 32.097 seconds overall. Standard passed 10/11 in 35.866 seconds overall, then 11/11 after programming. The cold cases made 37 Octavia write requests each and registered 528 and 534 reads respectively. The original assertion deadlines were unchanged. [Standard default-interval receipt](grpc-metadata-evidence/standard-default-resync.json) · [Experimental default-interval receipt](grpc-metadata-evidence/experimental-default-resync.json)

The fixture used Kubernetes API and etcd, Octavia REST and Amphora rendering, HAProxy 3.0.19, and four gRPC echo processes. It supplied Keystone, Neutron, worker completion, EndpointSlices and Pod readiness after probing the echo processes. The replay supplement includes the earlier fixture attempt and the Go traces.
